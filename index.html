观察模式可以旋转查看三维前后关系；切回绘制模式后，在选定深度的平面继续创作。此版本采用可调整深度的分层三维绘制，暂不支持任意点物理折弯。

03 · 加入展馆并自由摆放

完成多段绘制后，点击下方按钮，整组铁丝会进入左侧装置空间。再用彩色三轴手柄拖动，决定其具体位置；无需固定的三个连接点。

04 · 编辑已放置的作品

尚未选中作品。加入作品后会自动选中，也可以在左侧点击自己画的彩色铁丝。

你可以反复编辑自己创作的铁丝，确认位置后发布到云端；已发布作品之后的空间调整也会同步。他人作品只读。实体碰撞、自动打结尚未实现。

05 · 多人共享 / CLOUD SHARING

使用 Supabase 匿名身份保存作品。所有观众可观看彼此的铁丝，但只能调整自己创建的作品。更换浏览器可能失去原账号的修改权限，请保留本机备份。

本模块是于振立艺术纪念展《你为什么画星星？》的策展交互原型，而非艺术家原作。接入 Supabase 后，创作的三维路径和位置会在不同访客间共享；本机浏览器也保留 JSON 备份。公开展览前应配置匿名登录反滥用、适当的作品审核。当前展馆按参考图近似建模，今后可替换为正式 GLB/GLTF 模型。
